# Cover images go here

Drop the 4 Deepify book covers in this folder with these exact filenames:

- `book-3a.png` — Build Your AI Second Brain
- `book-3b.png` — Build Your AI Second Brain 201
- `voice-agent.png` — Build Your Own AI Agent
- `local-ai.png` — Local AI Infrastructure

Then run `bash samples/deepify-promo/setup.sh` from the repo root — it copies each cover into the 3 variation folders for its book.

The PNG files themselves aren't committed to git (covers are a product asset, not code).
